# Rules of the plausibility check: ID <TAB> severity <TAB> text
#
# IDs are those of the official rule sets (EN 16931 validation artefacts of CEN,
# XRechnung schematron of KoSIT, Peppol rules used by XRechnung), so that results
# can be compared. The texts are our own short wording.
# Severity follows the official flag: fatal = error, warning = warning.
#
# Own checks of abdecker that no official rule set demands get IDs starting with
# AB- (e.g. AB-VAT-RATE). They are reported with origin "extra" ("extra check"),
# like official rules applied beyond their rule set (R120 outside XRechnung/Peppol).
# Edit this file, then run: python tools/gen-data.py
