== help check
$ abdecker help check
exit: 0
stdout:
  Usage: abdecker check <input.pdf|input.xml> [options]
  
  Checks an e-invoice against the rules of EN 16931 and, for XRechnung, the
  XRechnung and Peppol rules. Rule IDs are the official ones (BR-..., BR-DE-...);
  "(extra check)" marks checks beyond the official rules. A plausibility check,
  not a replacement for the official validators.
  
  With -v, the report lists every rule of the applied rule sets: passed,
  failed, or not applied (the invoice does not contain what the rule is about,
  or it cannot be decided; see the list of what was not checked).
  
  "-" as input reads from standard input.
  
  Options:
    --json                  machine-readable output
    -v, --verbose           list every rule by status (--json: the field "rules")
    --fail-on <level>       error (default): exit code 1 on errors;
                            warning: also on warnings
  
  Exit codes:
    0  no errors (with --fail-on warning: no warnings either)
    1  errors found (with --fail-on warning: also warnings),
       or no (readable) e-invoice
    2  failure: file, usage, encrypted PDF, internal error
  
  Examples:
    abdecker check invoice.xml --fail-on warning
    abdecker check invoice.pdf -v
